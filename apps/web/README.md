This is the Next.js operator dashboard for `ai-growth-ops-platform`.

## Development

First, run the development server:

```bash
npm run dev
```

Open `http://localhost:3000`.

The preferred full-stack local workflow is managed from the repository root:

```bash
npm run dev
```

This app uses the App Router, TypeScript, Tailwind CSS, and Next.js 16.
