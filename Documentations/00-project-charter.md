# Project Charter

## Project Name

`ai-growth-ops-platform`

## Workspace

`F:\Codex Projects\ai-growth-ops-platform`

## Purpose

Create a professional, maintainable workspace for a new independent AI-assisted growth operations platform.

The project should support long-term collaboration between human maintainers and AI coding agents, with clear documentation, version control, and compliance boundaries.

## Product Direction

The platform should focus on compliant business growth operations:

- Customer development and lead qualification
- CRM workflow automation
- Brand reputation monitoring
- AI-assisted content drafting
- Review invitation and response workflows
- Reporting, auditability, and operational monitoring

## Non-Goals

This project should not implement systems for fake reviews, unauthorized account automation, platform control evasion, unsolicited mass messaging, credential abuse, or bypassing verification systems.

## Initial Success Criteria

- The workspace has a clear repository structure.
- Git can track documentation, code, scripts, tests, and infrastructure separately.
- Future Codex sessions can quickly understand project scope and boundaries.
- Architecture decisions are documented as the project evolves.
