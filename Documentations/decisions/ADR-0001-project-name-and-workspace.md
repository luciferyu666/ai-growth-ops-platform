# ADR-0001: Project Name and Workspace

## Status

Accepted

## Context

The project is a new independent software R&D effort intended for long-term AI-assisted development, Git/GitHub management, and persistent Codex sessions.

The workspace path is:

`F:\Codex Projects\ai-growth-ops-platform`

## Decision

Use `ai-growth-ops-platform` as the project folder and repository name.

## Rationale

The name is:

- Professional and descriptive
- Short enough for CLI and Git workflows
- Suitable for GitHub repository naming
- Broad enough to support CRM, AI, workflow automation, reputation management, and reporting modules
- Specific enough to distinguish the project from generic marketing tools

## Consequences

Future package names, repository names, deployment project names, and documentation should use `ai-growth-ops-platform` unless a more specific product brand is selected later.
